API-Hinweise:

• User besitzt genau eine Profile-Instanz (1:1).

• Ein Business kann mehrere Offers erstellen (1:N).

• Jedes Offer besitzt genau drei OfferDetails.

• Eine Order wird aus einem OfferDetail erstellt.

• Ein Kunde kann mehrere Orders erstellen.

• Ein Business kann mehrere Orders erhalten.

• Ein User kann ein Business nur einmal bewerten.

• Review: UNIQUE(reviewer_id, business_id).

• features werden als JSONField gespeichert.

API-Endpunkte:

• /api/users/

• /api/profile/

• /api/offers/

• /api/offerdetails/

• /api/orders/

• /api/reviews/

HTTP-Methoden:

• GET → Daten abrufen

• POST → Daten erstellen

• PATCH → Daten ändern

• DELETE → Daten löschen
